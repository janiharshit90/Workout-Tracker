## The app is now called Rarelift 🎉

New name, new look, and it's getting ready for Google Play. **Your workouts come with you**, but this
one update has to be done by hand, because Android sees Rarelift as a new app.

**Takes 2 minutes:**
1. In this app: **Settings → Back up data** and save the file.
2. Download **Rarelift-2.0.0.apk** below and install it. It installs next to this app.
3. Open Rarelift: **Settings → Restore from backup** and pick the file.
4. Check your history is all there, then uninstall the old "Mentzer Tracker".

From then on Rarelift updates itself as usual. (The old app will say this update is "a different
app". That's expected, so follow the steps above.)
